Dawn Patrol: a paper-trading bot for make.fun's Pump.fun Replay Sprint. It watches every new pump.fun bonding curve from its CreateEvent, reads the opening tape in batch orders per time slot, and buys only launches whose early tape looks like real crowd interest — creator has not sold, several distinct wallets buying, buys outweighing sells, price not already run away, net SOL still flowing in. It exits on a stop loss, a tight trailing stop once up, a hold limit, and instantly when the creator sells. Paper trading only: the replay uses market data, never real funds.

node main.ts
